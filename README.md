# Clinique Lumea — concept de clinique esthétique

Site vitrine fictif d'une clinique de médecine esthétique à Paris. Projet de portfolio.

Une seule page statique (`index.html`) et ses images (`images/`), sans build : HTML, CSS et JavaScript natifs, GSAP chargé depuis cdnjs.

Pour le voir en local, ouvrir `index.html` dans un navigateur.
